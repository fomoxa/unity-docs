# Glossary

| Term | Meaning |
|---|---|
| Adapter | The generated `IMessageCodec<T>` for one model and codec, such as `ShotNetAdapter`. See [models](../messaging/models.md). |
| Authoritative state | The server's result for a tick, sent to the owner for reconciliation. |
| Behaviour index | The position of a `NetworkBehaviour` in its object's behaviour list; messages to the object carry it. |
| Bundle | One transport frame holding several messages. |
| Channel | `Unreliable` or `ReliableOrdered`; set per message id. See [channels](../messaging/channels.md). |
| Codec | A named way to encode a model, generated by `fomoxac`. A model can have several. |
| Collection | A `NetworkList`, `NetworkDictionary` or `NetworkSet` registered with `NetworkState.Use`; the server sends the operations called on it. See [collections](../synchronization/collections.md). |
| Delta | The XOR of a state's new and previous encoding, with unchanged runs compressed. |
| Fingerprint | A hash of a prefab's or scene object's list of `NetworkBehaviour` types, compared at spawn. |
| Fragment | One piece of a `ReliableOrdered` message larger than the frame budget. The receiver joins the fragments before it delivers the message. See [message size](../messaging/channels.md#message-size). |
| Frame budget | The largest frame the package builds for a transport: 1200 bytes for UDP. |
| Grant | The bytes from `ConnectTokens.Issue` that let a client connect over [encrypted UDP](../connections/transports/encrypted-udp.md): a token and the client's session keys. |
| Host | A process that runs a server and a client in the same `NetworkManager`. See [host mode](../connections/host-mode.md). |
| Input model | The model a behaviour registers with `NetworkInput.Use`, sent each tick by the owner. |
| Interpolation | Showing a remote object between received transforms, a few ticks in the past. |
| Layer 1 | `Fomoxa.Networking`, the Core: the part of the package that does not reference Unity. |
| Layer 2 | `Fomoxa.Unity`, the Unity integration. |
| Message id | The 32-bit id of one model and codec in the schema. |
| Model | A C# class marked with `[Network]` that describes a message. |
| Network scene | A scene the server loads additively on itself and on chosen peers. See [network scenes](../objects/scenes.md). |
| `NetworkObject` | A GameObject that exists on the network, with an object id and an owner. |
| Object id | The id the server assigns to a `NetworkObject` when it spawns. |
| Observer | A peer that receives an object. See [observers](../objects/observers.md). |
| Owner | The peer an object belongs to; 0 for the server. |
| Peer id | The id of a connected client on the server; never 0. |
| Prediction | Applying the owner's input on its client before the server confirms it. |
| Prediction tick | The tick a client's input is for, ahead of the server tick. |
| Prefab id | The 32-bit id of a prefab, derived from its asset GUID unless set explicitly. |
| Proxy | On a client, the kinematic body of an object it does not predict, placed at its replicated position. |
| Reconcile model | The model a behaviour registers with `NetworkInput.Reconcile`, compared after each tick. |
| Reconciliation | Comparing the authoritative state with the prediction and correcting on a mismatch. |
| Replay | Applying recorded input again after a correction. Not a match recording. |
| Rollback | Restoring an earlier state, of a behaviour or of physics worlds, before a replay. |
| Rollback group | The physics worlds that are rolled back together. See [rollback](../prediction/rollback.md#rollback-groups). |
| Root set | The certificates a client trusts when it checks a TLS server: by default Mozilla's list, bundled with the package. See [client TLS](../connections/transports/tls.md). |
| Scene id | The 32-bit id of a scene, derived from its asset GUID. |
| Scene object | A `NetworkObject` placed in a scene, identified by a scene object id. |
| Schema | The list of every message id and its layout, generated as `NetSchema`; compared during the handshake. |
| Settle | The reliable message `NetworkTransform` sends when an object stops, spawns or teleports. |
| State model | The model a behaviour registers with `NetworkState.Use`, kept in sync by the server. |
| System model | One of the package's own models, such as `ObjectSpawn`. |
| Tick | One fixed step of the network simulation. See [ticks and timing](../concepts/tick.md). |
| Ticket | The bytes a server gives a client it transfers, which the new server's authenticator checks. See [server transfer](../connections/transfer.md#the-ticket). |
| Transfer | Moving a client from one server to another with `ServerManager.Transfer`. See [server transfer](../connections/transfer.md). |
| World | One Unity physics scene, 3D or 2D, seen through `IPhysicsWorld` or `IPhysicsWorld2D`. |
